# قرارداد دادهٔ فصل ششم

`orders.csv` دادهٔ ساختگیِ تألیفی و مستقل از رکوردهای فصل‌های قبل است. برای تمرین آموزشی استفاده می‌شود؛ نمایندهٔ قیمت بازار یا عملکرد واقعی فروشگاه نیست.

- ۱۲ سطر، هر سطر یک سفارش تک‌قلمی؛ شناسه‌ها یکتا.
- سه گروه: Books، Digital، Stationery؛ هرکدام چهار سفارش.
- تاریخ‌های متنی ISO از 2026-10-01 تا 2026-10-06؛ تاریخ سفارش، نه زمان بازپرداخت.
- تعداد اولیه صحیح مثبت؛ قیمت واحد صحیح نامنفی به تومان؛ تعداد برگشتی صحیح بین صفر و تعداد اولیه.
- همهٔ ستون‌ها و مقادیر موجودند؛ بدون مالیات، تخفیف، هزینه و تخصیص چندقلمی.
- بازپرداخت واحد برگشتی برابر قیمت اولیهٔ همان واحد است.
- فقط اعداد کوچک در محدودهٔ محاسبهٔ امن int64؛ این فصل سامانهٔ مالی عمومی یا اعتبارسنج همهٔ ورودی‌ها نیست.
- فایل UTF-8 با نویسه‌های ASCII، جداکنندهٔ ویرگول و یک سطر سرستون است.

| ستون | نقش |
|---|---|
| order_id | شناسهٔ متنی؛ برای شمارش یکتا، نه جمع‌زدن |
| order_date | تاریخ سفارش به‌صورت متن؛ در تحلیل این فصل استفادهٔ زمانی ندارد |
| category | گروه کالا |
| quantity | تعداد واحد اولیه |
| unit_price_toman | قیمت واحد به تومان |
| returned_quantity | تعداد واحد برگشتی |

بررسی‌های `load_orders` شامل ساختار، نبود مقدار گمشده، یکتایی شناسه، گروه مجاز و دامنه‌های ساده است. تاریخ، نبود رکورد مفقود، اصالت منبع، فاصله‌های اضافی همهٔ متن‌ها و سرریز عمومی بررسی نمی‌شوند. فایل نامعتبر نباید با پنهان‌کردن خطا وارد محاسبه شود.

این داده تصویر ثابتی از وضعیت مرجوعی سفارش‌هاست؛ از جمع به تفکیک تاریخ سفارش، نباید بازپرداخت روزانه یا جریان نقدی روز وقوع مرجوعی برداشت کرد.
