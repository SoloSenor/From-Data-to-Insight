# نقشهٔ منابع فصل یازدهم

## روش تألیف

ساختار فصل، ۳۰ مثال، ۱۲ تمرین، ۸ خطای عمدی و ارتقای پروژهٔ سفارش‌ها تألیف این کتاب‌اند، نه ترجمهٔ متوالی منابع. مثال‌ها یا عبارت‌های منبع به‌عنوان متن پیوسته منتقل نشده‌اند. شمارهٔ بخش و عنوان برای بازیابی آمده؛ شمارهٔ صفحهٔ چاپی وابسته به نسخه است.

| بخش فصل | منبع پشتوانه | دامنهٔ استفاده |
|---|---|---|
| ۱۱ـ۲ تا ۱۱ـ۵ | Introducing Python، ویرایش دوم، Bill Lubanovic، O’Reilly، 2019؛ بخش Handle Errors with try and except و بخش‌های فصل Be a Pythonista | الگوی مدیریت خطا و عادت اشکال‌زدایی؛ نه پروژهٔ دادهٔ مرجع |
| ۱۱ـ۷، ۱۱ـ۱۰، ۱۱ـ۱۱ | همان منبع؛ Test with unittest و مباحث Debugging و logging | جهت آموزشی و طرح استقلال تست؛ نمونه‌ها بازتألیف شده‌اند |
| ۱۱ـ۲ تا ۱۱ـ۵ | Python 3.11 Tutorial، Errors and Exceptions | ترتیب handler، else/finally، raise، زنجیرهٔ علت و استثنای اختصاصی |
| ۱۱ـ۶ | Python 3.11 Language Reference، The assert statement | حذف assert با بهینه‌سازی؛ مرز کنترل لازم‌الاجرا |
| ۱۱ـ۷ و ۱۱ـ۱۳ | Python 3.11 Library Reference، unittest | discovery، TestCase، subTest، addCleanup و runner |
| ۱۱ـ۸ | Python 3.11 Library Reference، math.isclose و isfinite | معیار نزدیکی و کنترل مقدار غیرمتناهی |
| ۱۱ـ۱۰ و ۱۱ـ۱۱ | Python 3.11 Library Reference، logging و pdb | کانال تشخیص، مشاهدهٔ وضعیت و گام‌برداری |
| ۱۱ـ۱۲ | Python 3.11 Library Reference، csv و contextlib.closing | parsing، رکورد منطقی و مالکیت مولد فایل‌دار |
| ۱۱ـ۱۲ تا ۱۱ـ۱۷ | فصل دهم همین پروژه و قرارداد کتاب | تداوم داده، oracle دستی، محدودیت تحلیل و تفکیک شاهدها |

نسخهٔ متن منابع رسمی errors، unittest و assert در فضای بازبینی پروژه خوانده شد؛ نام‌های فایل در محیط تدوین به‌ترتیب errors-docs.txt، unittest-docs.txt و assert-docs.txt هستند. excerptهای منابع داخل ZIP توزیع نشده‌اند. برای math، pdb، logging، csv و contextlib، لینک‌ها ارجاع تکمیلی برای مطالعه‌اند؛ ادعای مرور کامل همهٔ صفحات وب در این انتشار مطرح نیست. رفتارهای استفاده‌شده نیز با اجرای کد بررسی شده‌اند.
