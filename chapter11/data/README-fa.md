# دادهٔ مرجع فصل ۱۱

CSV و JSON بدون تغییر از فصل دهم کپی شده‌اند؛ JSON مسیر تولید گزارش نیست، مرجع تطبیق رکوردهاست. ۱۲ رکورد نمونهٔ آموزشی‌اند، نه دادهٔ واقعی مشتری. تاریخ‌ها میلادی canonical و مبلغ‌ها integer تومان‌اند. ناخالص ۵٬۰۲۰٬۰۰۰، برگشت ۱٬۴۳۰٬۰۰۰ و باقی‌مانده ۳٬۵۹۰٬۰۰۰ تومان است. باقی‌مانده سود نیست و schema صحت بیرونی یا کامل‌بودن معاملات را اثبات نمی‌کند.
