# فصل دوم — فایل‌های همراه

این پوشه شامل متن کامل فصل، خلاصهٔ گیت‌هاب و ابزارهای کوچک آزمون محیط است. متن، مستقل از تصویر قابل‌مطالعه است؛ سه پرامپت تصویر در محل مناسب متن کامل قرار دارند.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `chapter-02-full-fa.txt` | متن کامل، جدول‌ها، تمرین‌ها، پاسخ‌ها و منابع |
| `chapter-02-summary-fa.md` | خلاصهٔ تخصصی برای گیت‌هاب |
| `requirements.in` | نیازهای مستقیم؛ **بدون تثبیت نسخه و نه فایل قفل** |
| `smoke_check.py` | گزارش مفسر و حداقل بررسی‌های فصل |
| `notebooks/02-environment-check.ipynb` | دفترچهٔ تمرینی بدون خروجی ذخیره‌شده |
| `environment-notes.txt` | الگوی ثبت مشخصات محیط خواننده |
| `.gitignore` | قواعد اولیهٔ نادیده‌گرفتن فایل‌های نامناسب برای مخزن |
| `TEST-REPORT.txt` | محیط و حدود واقعی آزمون فایل‌ها |

## شروع

1. بسته را در پوشه‌ای مجاز استخراج کنید و ترمینال را در همان پوشه باز کنید.
2. با مفسر بررسی‌شده، محیط `.venv` بسازید و آن را فعال کنید. دستور دقیق Windows، macOS و Linux در متن فصل آمده است.
3. مسیر `python` را بررسی و سپس نصب کنید:

```bash
python -m pip install -r requirements.in
python -m pip check
python smoke_check.py
```

4. هسته را ثبت و JupyterLab را اجرا کنید:

```bash
python -m ipykernel install --user --name data-book --display-name "Python (data-book)"
python -m jupyterlab
```

5. دفترچه را باز و هستهٔ پروژه را انتخاب کنید؛ سپس Restart و Run All انجام دهید.
6. الگوی یادداشت محیط را با اطلاعات دستگاه خود تکمیل و در صورت نیاز نسخه‌های نصب را ثبت کنید:

```bash
python -m pip freeze > requirements-snapshot.txt
```

فرمان‌های بالا پس از ساخت و انتخاب محیط پروژه‌اند؛ در پایتون عمومی سیستم اجرا نشوند. اگر فعال‌سازی مجاز نیست، از مسیر صریح مفسر محیط استفاده کنید.

## حدود و امنیت

- هدف نصب جدید، CPython معمولی 3.14 است؛ آزمون اجرایی فایل‌ها روی Python 3.11.16 / Linux بوده است. گزارش آزمون را بخوانید.
- `.venv` محفظهٔ امنیتی نیست و نباید در مخزن قرار گیرد.
- اطلاعات شخصی، رمز و token را منتشر نکنید. خروجی دفترچه می‌تواند مسیر خصوصی دستگاه را نشان دهد.
- فایل snapshot، نسخهٔ Python و اجزای سیستم را ثبت نمی‌کند و تضمین اجرای یکسان روی همهٔ پلتفرم‌ها نیست.
- فایل‌های نمونه دادهٔ خارجی یا اطلاعات شخصی ندارند. این عبارت، مجوز بازنشر عمومی کل کتاب نیست.
