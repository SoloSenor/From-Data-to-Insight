# ردیابی منابع فصل چهارم

فصل تألیفی است؛ متن پیوسته، جدول و تصویر هیچ منبعی بازنشر نشده است. بررسی بخش‌های زیر به معنی مطالعهٔ خط‌به‌خط تمام منابع نیست. منابع اصلی به دلیل ارتباط مستقیم با مبانی زبان انتخاب شده‌اند؛ منابع آمار، آماده‌سازی داده و یادگیری ماشین برای این فصل اولویت ندارند.

شمارهٔ خط به فایل استخراج‌شدهٔ همین پروژه وابسته است؛ عنوان بخش برای شناسایی منبع پایدارتر است. شناسنامهٔ نسخهٔ نامطمئن حدس زده نشده است. فایل‌های PDF در بستهٔ آموزشی بازتوزیع نمی‌شوند.

## اصلاح ساده‌سازی‌های منابع قدیمی
- بیان قدیمی «دیکشنری ترتیب خاصی ندارد» به نسخه‌های فعلی تعمیم داده نشده است؛ تضمین ترتیب درج از Python 3.7 در متن ذکر می‌شود. حفظ ترتیب درج با دسترسی موقعیتی یا مرتب‌بودن بر اساس کلید متفاوت است.
- keys، values و items «نما» معرفی شده‌اند؛ تبدیل به list برای مشاهده توضیح داده می‌شود.
- شرط فنی کلید و عضو، hashable بودن است؛ تغییرناپذیری به‌تنهایی به‌صورت قاعدهٔ مطلق معرفی نشده است.
- مثال مرتب‌سازی مخلوط عدد و متن بازاجرا می‌شود؛ متن قدیمی دربارهٔ تبدیل عددها، مجوز تبدیل خودکار رشتهٔ عددنما تلقی نشده است.
- تاپل، تضمین تغییرناپذیری عمیق یا صحت دامنهٔ داده معرفی نشده است.
- set برای فراوانی رخدادها یا تشخیص خودکار تکرار رکوردها پیشنهاد نشده است.

## مستندات تکمیلی و حدود اعتبار
نشانی‌های رسمی Python در پایان متن فصل آمده‌اند؛ گزارش واکشی تازهٔ آن صفحات در این نوبت ارائه نمی‌شود. رفتار نمونه‌ها و بعضی حالت‌های مرزی در محیط ثبت‌شده در TEST-REPORT.txt اجرا می‌شود. این آزمون جایگزین اثبات همهٔ رفتارها و نسخه‌ها نیست.
