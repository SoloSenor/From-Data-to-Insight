## قرارداد کد و انتقال به Word
همهٔ کدهای Python در این فصل، حتی نام‌ها، کلیدها، رشته‌ها و توضیحات داخل کد، انگلیسی و ASCII هستند. خروجی نمونه‌ها نیز ASCII است. توضیح فارسی در متن و سلول Markdown قرار دارد، نه در سلول کد.

برای انتقال به Word:
۱. کد و خروجی را در پاراگراف مجزا و با جهت **چپ‌به‌راست** قرار دهید.
۲. قلم تک‌عرض مانند Consolas یا Courier New انتخاب کنید.
۳. تورفتگی‌ها، ویرگول‌ها و علامت نقل‌قول سادهٔ انگلیسی را حفظ کنید؛ نقل‌قول هوشمند Word نباید جایگزین علامت‌های کد شود.
۴. توضیح فارسی را بیرون پاراگراف کد قرار دهید. استفاده از نویسه‌های ASCII کمک می‌کند، ولی نمایش تمام نسخه‌های Word در این نوبت آزموده نشده است.

## اجرای مثال‌ها
از ریشهٔ همین پوشه، با Python 3:

```bash
python examples/04-examples.py
python examples/04-orders-workshop.py
python solutions/04-solutions.py
python -m unittest discover -s tests -v
```

اسکریپت مثال‌ها، بلوک‌ها را پشت‌سرهم چاپ می‌کند؛ مرز هر بلوک با توضیح انگلیسی BEGIN/END در منبع مشخص است. آزمون‌ها هر بلوک را مستقل در فضای نام تازه نیز اجرا می‌کنند. C22 خروجیِ عمداً نادرست از نظر معنایی دارد و C23 ناسازگاری مقدار مشتق‌شده را نشان می‌دهد؛ بدون خطا اجراشدن آن‌ها به معنی درست‌بودن گزارش نیست.

کد آموزشی و آزمون اصلی فقط به کتابخانهٔ استاندارد نیاز دارند. مدیریت عمومی ورودی نامعتبر پیاده‌سازی نشده است.

## دفترچهٔ Jupyter
فایل دفترچه برای Python 3 است. هسته را از نو راه‌اندازی و همهٔ سلول‌ها را از ابتدا اجرا کنید. دفترچهٔ منتشرشده خروجی ذخیره‌شده ندارد و شامل ۲۴ سلول کد سالم است؛ خطاهای عمدی در آن اجرا نمی‌شوند. توضیح کامل فصل و تمرین‌ها در فایل متن قرار دارد.

آزمون اختیاری اجرای واقعی هسته به `nbformat`، `nbclient` و `ipykernel` و هستهٔ ثبت‌شده با نام `python3` نیاز دارد. نسخه‌های واقعاً موجود در محیط آزمون در گزارش ثبت می‌شوند؛ ادعای نصب تازه یا قفل کامل محیط مطرح نیست.

```bash
python tests/check_notebook_kernel.py
```

این آزمون هستهٔ واقعی راه می‌اندازد، کدها و خروجی‌ها را با متن فصل تطبیق می‌دهد و نتیجه را در حافظه نگه می‌دارد؛ دفترچهٔ منتشرشده را با خروجی بازنویسی نمی‌کند. این آزمون معادل بازکردن مرورگر یا آزمون رابط JupyterLab نیست.

## حدود کارگاه
کارگاه فقط سه سفارش تک‌قلمی مشخص را پردازش می‌کند؛ هر رکورد دارای تعداد اولیه، قیمت واحد صحیح بر حسب تومان و تعداد برگشتی معتبر است. بازپرداخت کامل همان قیمت فرض شده و سایر هزینه‌ها و تعدیل‌ها وجود ندارند. با اضافه‌کردن رکورد چهارم، محاسبه خودکار گسترش نمی‌یابد. تعمیم با حلقه و تابع در فصل پنجم انجام می‌شود.

انتظار کنترل مستقل: مبلغ اولیه **۱٬۱۸۰٬۰۰۰**، بازپرداخت **۵۴۰٬۰۰۰** و مبلغ پس از مرجوعی **۶۴۰٬۰۰۰ تومان**. عدد آخر سود نیست. قیمت‌های واحد را برای محاسبهٔ مبلغ کل با هم جمع نکنید.

## یکپارچگی بسته
`MANIFEST.sha256` هش فایل‌های منتشرشده را، به‌جز خود manifest، نگه می‌دارد. پوشه‌های cache و دفترچهٔ اجرایی موقت در ZIP قرار نمی‌گیرند. جزئیات بررسی نهایی در گزارش آزمون آمده است.
