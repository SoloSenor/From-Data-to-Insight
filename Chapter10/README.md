# فصل دهم — ماژول‌ها و مفاهیم کاربردی زبان

امین، این بسته مستقل است؛ فصل‌های قبلی را بازنویسی نمی‌کند. متن تألیفی است و برای دنبال‌کردن مسیر آن، آشنایی با فصل‌های ۱ تا ۹ توصیه می‌شود.

## از کجا شروع کنیم؟
۱. chapter-10-fa.docx برای مطالعه و انتقال به Word؛ متن مرجع در chapter-10-full-fa.md و نسخهٔ متنی همسان در chapter-10-full-fa.txt است.
۲. chapter-10-summary-fa.md برای مرور.
۳. notebooks/10-language-tools.ipynb برای ۳۰ مثال مستقل.
۴. run_analysis.py و order_report برای پروژهٔ تک‌گذرهٔ گزارش سفارش.
۵. examples برای کاتالوگ، پاسخ ۱۲ تمرین و ۸ خطای عمدی؛ tests برای کنترل‌ها.

## اجرای پروژه
Python 3.11 یا جدیدتر لازم است. برنامهٔ اصلی فقط کتابخانهٔ استاندارد دارد. پوشهٔ ZIP را کامل استخراج کنید؛ ترمینال را در پوشه‌ای باز کنید که run_analysis.py داخل آن است.

```text
python --version
python run_analysis.py
python -m order_report
```

دو فرمان آخر دو راه اجرای همان پروژه‌اند؛ هر کدام را مستقل اجرا کنید. در بعضی محیط‌ها نام فرمان python3 است. مسیر داده در برنامهٔ اصلی نسبت به فایل پروژه ساخته می‌شود. هیچ خروجی یا دادهٔ مرجع به‌طور پیش‌فرض بازنویسی نمی‌شود. خروجی مورد انتظار در outputs/report.txt آمده است. single_pass True برچسب طراحی است؛ آزمون مستقلِ ورودی یک‌گذره شاهد آن است، نه خودِ چاپ این عبارت.

## مثال‌ها و پاسخ‌ها
کاتالوگ‌های JSON فقط دادهٔ آموزشی‌اند؛ آن‌ها را به‌عنوان برنامه اجرا نکنید. کدهای مستقل و خروجی دقیق در متن فصل آمده‌اند. برای اجرای پشت‌سرهمِ نمونه‌ها و پاسخ‌ها از ریشهٔ فصل:

```text
python -m examples.run_examples
python -m examples.solutions
```

برای اجرا در ویرایشگر، کد هر مثال را در فایل تازه کپی کنید یا فایل C مربوط را در examples باز کنید. مثال‌های معمول به دادهٔ پروژه وابسته نیستند؛ پاسخ‌های P11 و P12 به پوشهٔ data نیاز دارند. از نام‌هایی مانند csv.py و json.py برای فایل خود استفاده نکنید.

## نصب ابزار کنترل کیفیت
نصب در محیط مجازیِ دلخواه توصیه می‌شود. فایل requirements-qa.txt قفل نسخه‌ها نیست؛ نسخه‌های واقعی اجرای منتشرشده در گزارش کرنل ثبت شده‌اند.

```text
python -m pip install -r requirements-qa.txt
python -m ipykernel install --user --name python3 --display-name "Python 3"
python -m unittest discover -s tests -v
python tests/check_notebook_kernel.py
```

برای اجرای Jupyter مرورگری یا VS Code، محیط notebook دلخواه شما باید جدا نصب و کرنل درست انتخاب شود؛ این بسته رابط مرورگری را آزمون نکرده است. کنترل کرنل از nbclient و kernelspec با نام python3 استفاده می‌کند؛ صرف نصب کتابخانهٔ پایتون وجود kernelspec را تضمین نمی‌کند. این ابزار نسخهٔ اصلی دفترچه را بازنویسی نمی‌کند.

## قرارداد علمی و محدودیت
کد، کامنت، رشته، docstring و خروجی‌های ثابت ASCII و انگلیسی‌اند. توضیح فارسی بیرون کد است. Word کدها را LTR و تک‌عرض نگه می‌دارد. JSON مرجع کامل در حافظه خوانده می‌شود. حذف فهرست همهٔ سفارش‌ها، حافظهٔ ثابت ایجاد نمی‌کند: مجموعهٔ شناسه‌ها O(n) و وضعیت دسته‌ها O(k) است. retained مبلغ باقی‌مانده پس از برگشت است، نه سود. validate_orders قرارداد آموزشی را می‌سنجد، نه حقیقت یا کامل‌بودن داده را.

TEST-REPORT.txt آزمون Python، اجرای واقعی Jupyter، کنترل ساختاری Word و محدودیت محیط را جدا گزارش می‌کند. فایل MANIFEST.sha256 برای فایل‌های بسته به‌جز خود manifest است؛ اعتبار آن به معنی امضای دیجیتال ناشر نیست.
