# فصل نهم: فایل‌ها، مسیرها و تبادل داده

این بسته مستقل است؛ اجرای پروژه به فصل‌های دیگر یا فایل منابع نیاز ندارد. کدها، رشته‌ها، توضیحات داخل کد و خروجی‌های آموزشی انگلیسی و ASCII هستند. توضیحات فارسی بیرون کد آمده‌اند.

## فایل‌های مطالعه
- `chapter-09-fa.docx`: فصل مستقل Word؛ بدون تغییر سند اصلی کتاب، با حفظ تعریف چهار استایل موجود آن.
- `chapter-09-full-fa.md` و `chapter-09-full-fa.txt`: متن کامل و یکسان فصل.
- `chapter-09-summary-fa.md`: خلاصهٔ تخصصی.
- `notebooks/09-files-and-data-exchange.ipynb`: ۳۰ مثال آموزشی.
- `SOURCE-MAP.md`: نقشهٔ منابع و حدود بازبینی.
- `TEST-REPORT.txt` و `qa-results/`: گزارش آزمون‌ها و شواهد اجرا.

فصل شامل ۳۰ مثال، ۱۲ تمرین (۴ مفهومی و ۸ کدنویسی با پاسخ)، ۸ خطای عمدی و پروژهٔ چندفایلی `order_report` است. تصویر نهایی تولید نشده؛ جایگاه و پرامپت پیشنهادی در متن آمده است.

## محیط و اجرای پروژه
محیط مرجع آزموده‌شده: Python 3.11.16 روی Linux. اجرای پروژه، مثال‌ها و آزمون‌های unittest فقط به کتابخانهٔ استاندارد نیاز دارد. نسخه‌های دیگر Python، Windows و macOS آزموده نشده‌اند. پیشنهاد این بسته Python 3.11 است؛ نحو آن برای Python 2 مناسب نیست.

ZIP را کامل استخراج کنید. فرمان‌های زیر را از پوشهٔ `chapter-09` اجرا کنید؛ اگر لازم بود `python3` را جایگزین `python` کنید:

```bash
python run_analysis.py
python -m order_report
python examples/09-examples.py
python examples/09-answers.py
```

دو فرمان نخست خروجی یکسان دارند:

```text
orders 12
gross_toman 5020000
refund_toman 1430000
retained_toman 3590000
Digital 2450000 68.25%
Books 690000 19.22%
Stationery 450000 12.53%
csv_json_equal True
round_trip_equal True
temporary_exports_removed True
```

پروژه CSV و JSON مرجع را می‌خواند و برابری رکوردها را کنترل می‌کند. خروجی‌های CSV، JSON و متن را در پوشهٔ موقت می‌نویسد، دو قالب داده را بازخوانی می‌کند و پوشهٔ موقت را پاک می‌کند؛ فایل‌های مرجع را بازنویسی نمی‌کند. `outputs/report.txt` خروجی کنسول مرجعِ ازپیش‌ساخته است، نه فایلی که اجرای عادی برنامه بازنویسی کند.

اجرای `run_analysis.py` با مسیر مطلق از پوشهٔ کاری دیگر نیز آزموده شده است. اجرای ماژولی به حضور ریشهٔ فصل در مسیر جست‌وجوی Python نیاز دارد؛ ساده‌ترین راه اجرای آن از همین پوشه است. بسته با pip نصب نشده است. ماژول‌های داخلی با import نسبی را مستقیم اجرا نکنید.

مثال‌ها و پاسخ‌ها از پوشهٔ موقت برای کار فایل استفاده می‌کنند. خطاهای عمدی در `examples/intentional-errors.json` جدا هستند و نباید در مسیر اجرای سالم قرار بگیرند. کدها و پاسخ‌های اجرایی در JSONهای همراه نیز با خروجی مرجع ثبت شده‌اند.

## دفترچه و آزمون‌ها
آزمون‌های Python بدون نصب ابزار Jupyter اجرا می‌شوند:

```bash
python -m unittest discover -s tests -v
```

برای اجرای کنترل کیفیت دفترچه:

```bash
python -m pip install -r requirements-qa.txt
python tests/check_notebook_kernel.py
```

این فایل نسخه‌های مستقیم مشاهده‌شدهٔ ابزارهای کنترل کیفیت را ثبت می‌کند؛ قفل همهٔ وابستگی‌های گذرا یا تضمین نصب در هر محیط نیست. ابزار کنترل به kernelspec با نام `python3` نیاز دارد. اگر ثبت نشده است، در محیط صحیح اجرا کنید:

```bash
python -m ipykernel install --user --name python3
```

دفترچهٔ تحویلی عمداً بدون خروجی و execution count است. ابزار کنترل آن را در هستهٔ واقعی و پوشهٔ کاری موقت اجرا می‌کند، خروجی هر ۳۰ سلول آموزشی را با مرجع تطبیق می‌دهد و با یک سلول اضافی محیط هسته را می‌سنجد؛ فایل منتشرشده را تغییر نمی‌دهد. خود دفترچه به داده یا ماژول محلی وابسته نیست. رابط مرورگری JupyterLab آزموده نشده و نصب آن در الزامات کنترل کیفیت منظور نشده است.

## داده و حدود قرارداد
`data/orders.csv` و `data/orders.json` دو نمایش همان ۱۲ سفارش ساختگی‌اند. واحد مبلغ تومان و تاریخ، میلادی با قالب دقیق `YYYY-MM-DD` است. قرارداد کامل در `data/README-fa.md` آمده است.

`validate_orders` فقط schema و قواعد مشخص آموزشی را بررسی می‌کند؛ حقیقت، کامل‌بودن واقعی، مجوز دسترسی یا کیفیت معنایی همهٔ داده‌ها را تضمین نمی‌کند. خواننده‌ها کل داده را در حافظه جمع می‌کنند. برخورد با نام تکراری در یک شیء JSON، رفتار پیش‌فرض `json.load` است: آخرین مقدار باقی می‌ماند. این موضوع با رد شناسهٔ تکراری بین سفارش‌ها متفاوت است.

نویسنده‌ها پیش از بازکردن مقصد اعتبارسنجی می‌کنند و پیش‌فرضشان حالت `x` است. والد مسیر را نمی‌سازند. `overwrite=True` اجازهٔ بازنویسی می‌دهد، اما نوشتن اتمیک، تراکنش یا بازیابی پس از قطع برق را تضمین نمی‌کند. مقدار نهایی **۳٬۵۹۰٬۰۰۰ تومان** مبلغ پس از مرجوعی است، نه سود.

## Word و سلامت بسته
در DOCX، کد و خروجی پاراگراف مستقل LTR با قلم تک‌عرض دارند. کنترل XML و بازخوانی سند انجام شده؛ اجرای خود برنامهٔ Microsoft Word انجام نشده است. تبدیل آزمایشی با LibreOffice یک PDF ۳۳صفحه‌ای ساخته و چند صفحهٔ منتخب آن بازبینی شده است؛ این عدد تضمین تعداد صفحات در Word شما نیست.

`MANIFEST-SHA256.txt` هش فایل‌های بسته به‌جز خودش را ثبت می‌کند. گزارش بیرون ZIP نتیجهٔ CRC، تطبیق manifest و اجرای دوباره از نسخهٔ استخراج‌شده را ثبت می‌کند. منابع کتابی و متن استخراج‌شدهٔ آنها در بسته بازنشر نشده‌اند.
