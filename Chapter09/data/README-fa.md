# قرارداد دادهٔ آموزشی فصل نهم

این دو فایل CSV و JSON نمایش یکسان ۱۲ سفارش ساختگی‌اند؛ دادهٔ عملیاتی یا شخصی نیستند.

شش ستون به ترتیب CSV:
`order_id`, `order_date`, `category`, `quantity`, `unit_price_toman`, `returned_quantity`.

- شناسه: متن غیرخالی و یکتا، بدون فاصلهٔ ابتدا/انتها؛ صفر ابتدایی شناسه باید حفظ شود.
- تاریخ: متن تاریخ معتبر میلادی با قالب دقیق `YYYY-MM-DD`.
- دسته: متن غیرخالی بدون فاصلهٔ ابتدا/انتها.
- تعداد: عدد صحیح مثبت.
- قیمت واحد: عدد صحیح نامنفی به تومان.
- تعداد مرجوعی: عدد صحیح بین صفر و تعداد سفارش.
- در قرارداد نهایی، bool و float جایگزین عدد صحیح نیستند. ریشهٔ JSON فهرست است؛ هر رکورد دقیقاً همین کلیدها را دارد.
- ترتیب سرستون CSV بخشی از قرارداد این نسخه است. سلول‌های عددی CSV با int تبدیل می‌شوند؛ فاصلهٔ عددی و علامت صریح پذیرفته‌شده توسط int مجاز است.
- UTF-8 و UTF-8 دارای BOM خوانده می‌شوند. خروجی نویسنده UTF-8 بدون BOM است.
- فهرست خالی مجاز است؛ CSV بدون سرستون معتبر نیست. خط‌های کاملاً خالی با رفتار DictReader نادیده گرفته می‌شوند.

مبلغ اولیه ۵٬۰۲۰٬۰۰۰، بازپرداخت ۱٬۴۳۰٬۰۰۰ و مبلغ پس از مرجوعی ۳٬۵۹۰٬۰۰۰ تومان است؛ مقدار سوم سود نیست.

اعتبارسنج فقط این قرارداد را کنترل می‌کند، نه حقیقت، کامل‌بودن واقعی یا کیفیت معنایی داده‌ها. نام تکراری در یک شیء JSON طبق پیش‌فرض parser با آخرین مقدار باقی می‌ماند؛ شناسهٔ تکراری بین رکوردها جداگانه رد می‌شود. داده کامل در حافظه خوانده می‌شود.
