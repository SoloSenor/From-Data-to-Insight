## شروع
از پوشهٔ همین فصل و بدون گزینهٔ `-O` اجرا کنید:

```bash
python examples/05-workshop.py
python examples/05-examples.py
python solutions/05-solutions.py
python -m unittest discover -s tests -v
python tests/check_notebook_kernel.py
```

مثال‌های آموزشی فقط به کتابخانهٔ استاندارد نیاز دارند. آزمون ساختار دفترچه به `nbformat` و اجرای هسته به `nbclient`، `jupyter_client` و `ipykernel` نیاز دارد. نسخه‌های نصب‌شده در محیط مرجع گزارش شده‌اند؛ این گزارش معادل آزمون نصب تازه نیست. برای راه‌اندازی محیط جداگانه می‌توان از نسخه‌های ثبت‌شده در `requirements-qa.txt` استفاده کرد؛ دسترسی شبکه و سازگاری سیستم مقصد جداگانه بررسی می‌شود.

دفترچه را با هستهٔ Python 3 از ابتدا تا انتها اجرا کنید. فایل منتشرشده بدون خروجی ذخیره شده است؛ بررسی خودکار هسته آن را تغییر نمی‌دهد. آزمون مرورگر و تعامل JupyterLab انجام نشده است.

## قرارداد آموزشی
کد، رشته، توضیح درون کد و خروجی‌ها انگلیسی و ASCII هستند. توضیح فارسی بیرون کد قرار دارد. در Word، کد و خروجی را در پاراگراف مستقل چپ‌به‌راست با قلم تک‌عرض و نقل‌قول مستقیم درج کنید.

۲۵ مثال با شناسهٔ C، هشت پاسخ کدنویسی با شناسهٔ A و شش خطای عمدی با شناسهٔ E مشخص‌اند. بلوک‌های سالم مستقل‌اند؛ فایل مثال‌ها آن‌ها را پشت سر هم هم اجرا می‌کند. خطاهای عمدی فقط در JSON هستند و در دفترچهٔ آموزشی اجرا نمی‌شوند. دوازده تمرین فصل همه الزاماً پاسخ کدنویسی ندارند.

## حدود اعتبار
ورودی‌های کارگاه معتبر فرض شده‌اند؛ توابع نوع، کلید، یکتایی شناسه یا دامنهٔ داده را کنترل نمی‌کنند. تعدادها صحیح و تعداد خرید مثبت، قیمت صحیح نامنفی به تومان، و برگشتی بین صفر و تعداد خرید است. تخفیف و مرجوعی دو سناریوی جدا هستند. مبلغ پس از مرجوعی سود نیست. آزمون‌های موفق تضمین همهٔ ورودی‌ها و نسخه‌ها نیستند.
