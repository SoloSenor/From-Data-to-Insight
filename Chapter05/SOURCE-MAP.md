# ردیابی منابع فصل پنجم

این فصل تألیفی است؛ منابع پشتوانهٔ مفهومی‌اند و متن یا مثال‌هایشان بازنشر نشده است. همهٔ صفحات منابع خط‌به‌خط بررسی نشده‌اند. منابع زبان پایتون به دلیل ارتباط مستقیم در اولویت‌اند؛ منابع تخصصی آمار و یادگیری ماشین در این فصل نقش اصلی ندارند.

| S2 | همان | فصل ششم، Repeat with while، break، continue و Iterate with for and in؛ خطوط ۳۴۹۱–۳۶۶۰ |
| S3 | همان | فصل نهم، Define a Function with def، Call a Function with Parentheses و Arguments and Parameters؛ خطوط ۵۶۶۸–۵۷۶۷ |
| S4 | Wes McKinney، Python for Data Analysis، نسخهٔ موجود پروژه؛ `review/Python for Data Analysis.txt` | فصل دوم، Control Flow؛ شاخه‌بندی، ارزیابی کوتاه، for، while و range؛ خطوط ۲۶۳۸–۲۸۰۷ |

شمارهٔ خط به نسخهٔ متن استخراج‌شده وابسته است، نه شمارهٔ صفحهٔ چاپی. شناسنامهٔ نسخهٔ نامطمئن حدس زده نشده است. PDFها در بستهٔ فصل بازتوزیع نمی‌شوند.

## دقت در استفاده از منابع
- توصیف ساده‌شدهٔ `range` به‌عنوان iterator عیناً تکرار نشده است؛ در Python 3 یک شیء دنباله‌ای تکرارپذیر است، نه خودِ iterator.
- مقدار بازگشتی `and` و `or` به bool بودن عمومی محدود نشده است؛ کاربرد شرطی با عبارت‌های بولی از کاربرد عمومی عملگرها جداست.
- توضیح ارسال آرگومان به معنای کپی مستقل یا عمیق داده تلقی نشده است. کارگاه ورودی را تغییر نمی‌دهد؛ این ویژگی از پیاده‌سازی و آزمون آن می‌آید، نه صرف تابع‌بودن.
- ویژگی‌های پیشرفتهٔ تابع، استثنا، درک فهرستی و سازمان‌دهی ماژول به فصل‌های بعد موکول شده‌اند.
- سیاست تخفیف با مرجوعی ادغام نشده تا قاعدهٔ تعریف‌نشدهٔ تخصیص تخفیف به بازپرداخت فرض نشود.

## حدود تأیید
رفتار کدها در محیط ثبت‌شده در `TEST-REPORT.txt` بررسی می‌شود؛ این کار مطالعهٔ کامل منابع، آزمون همهٔ نسخه‌ها یا تأیید همهٔ ورودی‌ها نیست. هیچ API قدیمی کتابخانه‌های تحلیل داده وارد مثال‌های این فصل نشده است. همهٔ کدها و خروجی‌های آموزشی ASCII هستند و متن فارسی بیرون کد است.
