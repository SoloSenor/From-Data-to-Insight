# نقشهٔ منابع فصل هفتم

## سیاست استفاده
فصل تألیفی است و مثال‌ها برای پیوستگی همین کتاب نوشته شده‌اند؛ ترجمه یا مونتاژ متن منابع نیست. فقط بخش‌های زیر از متن استخراج‌شده بازبینی شدند. شمارهٔ خط مربوط به فایل متنی است، نه لزوماً شمارهٔ صفحهٔ چاپی؛ علامت PAGE از فرایند استخراج PDF آمده است. هیچ ادعای مطالعهٔ کامل همهٔ صفحات یا همهٔ منابع نداریم.

| اولویت | منبع موجود در پروژه | بخش بازبینی‌شده | کاربرد |
|---|---|---|---|
| اصلی | Introducing Python O’Reilly Media - 2019.pdf | متن استخراج‌شده، خطوط 4260–4444؛ بخش‌های Assign، Copy، deepcopy و مقایسه و پیمایش فهرست | ارجاع، کپی کم‌عمق و عمیق و تغییر داخلی |
| اصلی | همان منبع | خطوط 4460–4619؛ zip و List Comprehension و Lists of Lists | پیمایش موازی، فیلتر و تبدیل و دادهٔ تودرتو |
| اصلی | همان منبع | خطوط 5212–5251؛ Dictionary Comprehensions | ساخت نگاشت و بازنویسی کلید تکراری |
| مکمل | Python for Data Analysis.pdf | متن استخراج‌شده، خطوط 3120–3264؛ Built-in Sequence Functions و dict | enumerate، sorted، zip و دسترسی به دیکشنری |
| پیوستگی کتاب | فصل چهارمِ تأییدشده | خلاصهٔ فصل چهارم | حفظ مرز با معرفی مقدماتی ساختارها و تکمیل کپی و مرتب‌سازی در فصل هفتم |
| دادهٔ مشترک | فصل ششمِ تأییدشده | data/orders.csv و خروجی مرجع | حفظ عین دادهٔ ساختگی و کنترل مستقل مبلغ‌ها |

فایل‌های متن منبع در /mnt/data/review هستند و برای جلوگیری از بازتوزیع غیرضروری PDF یا متن کتاب‌های دیگر، داخل بستهٔ فصل قرار نگرفته‌اند. خوانندهٔ بسته برای اجرای مثال‌ها به منابع اصلی نیاز ندارد.

## اصلاح و احتیاط نسخه‌ای
- بعضی بیان‌های منبع قدیمی دربارهٔ بی‌ترتیب‌بودن دیکشنری با Python مرجع کتاب سازگار نیستند؛ در متن حاضر حفظ ترتیب درج در Python جدید رعایت شده است.
- zip یک iterator مصرف‌شدنی است، نه فهرست آمادهٔ زوج‌ها. نتیجه در مثال‌ها صریحاً مصرف می‌شود.
- strict=True به متن منبع قدیمی نسبت داده نشده است؛ رفتار آن جداگانه در Python 3.11.16 اجرا و زمان وقوع خطا آزمایش شده است. این پارامتر از Python 3.10 در دسترس است.
- برابری طول با هم‌ترازی معنایی متفاوت است؛ هیچ قابلیت خودکار تشخیص اشتباه معنایی به zip نسبت داده نشده است.
- استقلال کپی کم‌عمق بر اساس سطح تغییر توضیح داده شده؛ deepcopy ابزار عمومی تکثیر منابع معرفی نشده است.
- جزئیات APIهای قدیمی pandas یا رسم نمودار در این فصل دخیل نیستند؛ کد تحلیل فقط کتابخانهٔ استاندارد است.

## کار تألیفی و صحت‌سنجی مستقل
داده از فصل ششم است. مسیر غنی‌سازی، جمع گروهی، قرارداد share در مخرج صفر، رتبه‌بندی چندمعیاره، شش خطای عمدی و تمرین‌ها برای این فصل طراحی شده‌اند. آزمونِ عددی با جمع قیمت تک‌تک واحدها در نمونه‌های کوچک، مرجع مستقلی از فرمول ضربی تابع می‌سازد. منبع کتابی، جای آزمون اجرای کد یا قضاوت دربارهٔ مخرج و معنای شاخص را نمی‌گیرد.
