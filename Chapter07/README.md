## اجرای تحلیل
از ریشهٔ این پوشه:

```bash
python run_analysis.py
python examples/07-examples.py
python examples/07-answers.py
```

این سه فرمان به بستهٔ خارج از کتابخانهٔ استاندارد نیاز ندارند. تحلیل در Python 3.11.16 آزموده شده است؛ نمونه‌های zip با strict به Python 3.10 به بعد نیاز دارند. خروجی تحلیل در outputs/report.json کنار اسکریپت نوشته و در اجرای بعد بازنویسی می‌شود. اسکریپت‌ها از پوشهٔ کاری دیگر نیز اجرا می‌شوند؛ دادهٔ خام تغییر نمی‌کند.

مثال‌های اصلی درون اسکریپت و دفترچه به ترتیب به هم وابسته‌اند؛ هر تکه به‌تنهایی اسکریپت مستقل نیست. پاسخ‌ها یک دادهٔ اولیهٔ مشترک دارند. هیچ خطای عمدی در مسیر سالم اجرا نمی‌شود؛ [کاتالوگ خطاها](examples/intentional-errors.json) فقط برای اجرای جداگانه است.

## دفترچه و کنترل کیفیت
برای اجرای آزمون‌ها در محیطی که Python و pip آن مشخص است:

```bash
python -m pip install -r requirements-qa.txt
python -m unittest discover -s tests -v
python tests/check_notebook_kernel.py
```

نصب بالا یک دستور پیشنهادی است؛ نصب تازه در محیط تمیز آزموده نشده است. requirements-qa.txt فقط نسخه‌های مستقیم مشاهده‌شده است، نه قفل تمام وابستگی‌ها. unittest نیز برای بررسی ساختار دفترچه به nbformat نیاز دارد. آزمون هسته به یک kernelspec قابل‌استفاده با نام python3 نیاز دارد؛ ممکن است مفسر kernelspec با مفسر اجرای فرمان یکسان نباشد و به همین دلیل مشخصات هر دو در نتیجه ثبت می‌شود. مرورگر و JupyterLab UI آزموده نشده‌اند.

برای بازکردن فایل ipynb از محیط Jupyter موجود خود استفاده کنید و همهٔ سلول‌ها را از ابتدا اجرا کنید. فایل منتشرشده عمداً بدون خروجی ذخیره شده است. دستور ثبت kernelspec در صورت نبودن آن، باید در همان محیط موردنظر اجرا شود:

```bash
python -m ipykernel install --user --name python3 --display-name "Python 3"
```

این فرمان می‌تواند kernelspec هم‌نام موجود را تغییر دهد؛ در محیط مشترک ابتدا مشخصات محیط و نام مناسب را بررسی کنید. راه‌اندازی رابط مرورگر جزو آزمون این بسته نیست.

## حدود ادعا
کارگاه با ورودی معتبرِ کوچک کار می‌کند؛ فقط شناسهٔ تکراری را رد می‌کند. دادهٔ چندقلمی، اعتبارسنجی کامل، حسابداری، قیمت اعشاری و تحلیل زمانی در دامنه نیستند. کد اجرای درستِ همین قرارداد را آموزش می‌دهد، نه یک سامانهٔ آمادهٔ تولید.

همهٔ کدها و خروجی‌های آموزشی ASCII هستند. برای Word از پاراگراف مستقل چپ‌به‌راست و قلم تک‌عرض استفاده کنید. فایل Word تولید یا صفحه‌آرایی نشده است. دو پرامپت تصویر در متن آمده‌اند، اما تصویر نهایی تولید نشده است.

MANIFEST.sha256 برای کنترل تمامیت فایل‌هاست و خود manifest را پوشش نمی‌دهد. پوشه‌های cache، checkpoint و فایل‌های موقت در ZIP نیستند. مشخصات آزمونِ همین انتشار داخل qa-results ثبت شده است؛ تکرار آزمون‌ها ممکن است زمان اجرای متفاوتی بدهد.
