# فصل هفتم — ساختارهای داده و الگوهای پردازش

## هدف
تبدیل اجرای دستورها به طراحی مسیر پردازش روشن: پیش‌بینی تغییر، انتخاب سطح کپی، پیمایش، تبدیل، نمایه‌سازی، گروه‌بندی و رتبه‌بندی رکوردها. پیش‌نیاز: فصل‌های سوم تا ششم. تحلیل فقط با Python و کتابخانهٔ استاندارد است؛ pandas یا NumPy برای اجرای این فصل لازم نیست.

## مفاهیم کلیدی
| موضوع | قاعده | دام |
|---|---|---|
| انتساب | نام تازه می‌تواند به همان شیء برسد | انتساب کپی نیست |
| هویت و برابری | is برای هویت؛ == برای مقدار | استفاده از is برای مقایسهٔ عدد یا متن |
| کپی کم‌عمق | ظرف بیرونی مستقل می‌شود | ظرف‌های داخلی می‌توانند مشترک بمانند |
| کپی رکوردها | دیکشنری هر رکورد تازه می‌شود | فیلد فهرستی داخل رکورد هنوز ممکن است مشترک باشد |
| کپی عمیق | برای ظرف‌های معمول کپی بازگشتی می‌سازد | ابزار عمومی تکثیر منابع و فایل باز نیست |
| enumerate | شماره و عضو را با هم می‌دهد | شمارهٔ نمایشی، شناسهٔ پایدار نیست |
| zip | عضوهای هم‌موقعیت را جفت می‌کند | در حالت معمول در کوتاه‌ترین ورودی متوقف می‌شود |
| zip با strict | نابرابری طول هنگام مصرف خطا می‌دهد | هم‌ترازی معنایی را تضمین نمی‌کند |
| درک فهرستی | یک تبدیل یا فیلتر ساده را بیان می‌کند | برای اثر جانبی و منطق چندمرحله‌ای مناسب نیست |
| درک دیکشنری | کلید به مقدار می‌سازد | کلید تکراری بی‌صدا بازنویسی می‌شود |
| sorted | فهرست تازه و مرتب می‌سازد | رکوردهای داخلی عمیق کپی نمی‌شوند |
| sort | ترتیب همان فهرست را تغییر می‌دهد | مقدار برگشتی None است |
| کلید چندجزئی | ترتیب مقایسهٔ مؤلفه‌ها صریح می‌شود | reverse جهت همهٔ مؤلفه‌ها را معکوس می‌کند |

## قرارداد کارگاه
همان ۱۲ سفارش ساختگی فصل ششم؛ هر رکورد یک سفارش تک‌قلمی. تعداد صحیح مثبت، قیمت صحیح نامنفی، مرجوعی صحیح بین صفر و تعداد، شناسهٔ رشته‌ای یکتا. تاریخ در این فصل متن است. هزینه، تخفیف و مالیات نداریم؛ مبلغ پس از مرجوعی سود نیست.

مسیر: کنترل تکرار شناسه ← کپی رکورد ← محاسبهٔ سه مبلغ ← انباشتن گروهی ← تعیین مخرج ← رتبه‌بندی ← گزارش.

| شاخص | تومان |
|---|---:|
| مبلغ اولیه | ۵٬۰۲۰٬۰۰۰ |
| بازپرداخت | ۱٬۴۳۰٬۰۰۰ |
| مبلغ پس از مرجوعی | ۳٬۵۹۰٬۰۰۰ |

رتبهٔ مبلغ گروه‌ها: Digital برابر ۲٬۴۵۰٬۰۰۰؛ Books برابر ۶۹۰٬۰۰۰؛ Stationery برابر ۴۵۰٬۰۰۰ تومان. سهم مبلغ‌ها به‌ترتیب حدود ۶۸٫۲۵، ۱۹٫۲۲ و ۱۲٫۵۳ درصد است.

## قرارداد توابع
- index_unique شناسهٔ تکراری را رد می‌کند؛ مقدارهای نمایه ارجاع رکوردهای اصلی‌اند.
- build_report ترتیب و فیلدهای ورودی را تغییر نمی‌دهد؛ برای غنی‌سازی هر دیکشنری را کم‌عمق کپی می‌کند. این سطح کپی برای دادهٔ فعلی و تغییرات سطح اول کافی است، نه استقلال همهٔ داده‌های تو‌در‌تو.
- با مخرج صفر، سهم هر گروهِ مشاهده‌شده None است. ورودی خالی، فهرست گروه خالی می‌دهد.
- فقط شناسهٔ تکراری اعتبارسنجی می‌شود؛ تابع اعتبارسنج عمومی schema و قیمت و تعداد نیست.
- ورودی تابع یک فهرست معتبر است؛ پشتیبانی از iterator یک‌بارمصرف ادعا نمی‌شود.

## خطاهای منطقی مهم
۱. تکرار یک فهرست داخلی با ضرب، زیرظرف‌های مستقل نمی‌سازد.
۲. dict.fromkeys با یک فهرست، مقدار مشترک به کلیدها می‌دهد.
۳. حذف از فهرست در حال پیمایش می‌تواند عضوها را جا بیندازد.
۴. sorted ظرف تازه می‌سازد ولی اشتراک رکوردها را قطع نمی‌کند.
۵. تخت‌کردن قلم‌ها، واحد مشاهده و پوشش سفارش‌های خالی را تغییر می‌دهد.
۶. مبلغ صفر، به‌تنهایی نشانهٔ مرجوعی کامل نیست.

## محتوای تحویل
۳۰ مثال پیوسته، ۱۲ تمرین شامل ۴ پاسخ مفهومی و ۸ پاسخ کدنویسی، ۶ خطای عمدیِ جدا، دفترچهٔ Jupyter، اسکریپت مثال‌ها و پاسخ‌ها، تحلیل مستقل، دادهٔ JSON و literal پایتون، گزارش JSON و آزمون‌ها. دو جایگاه تصویر با پرامپت ارائه شده‌اند؛ تصویر نهایی تولید نشده است.

کدها، رشته‌ها، توضیحات داخل کد و خروجی‌ها انگلیسی و ASCII هستند. برای Word جهت چپ‌به‌راست، قلم تک‌عرض و حفظ تورفتگی لازم است. ظاهر Word آزموده نشده است.
