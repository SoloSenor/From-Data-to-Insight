## اجرای فایل

در ترمینال، پس از فعال‌کردن محیط فصل دوم، به پوشهٔ همین فصل بروید:

```bash
python examples/03-order-report.py
```

این فرمان، شش سطر گزارش سفارش `O-0301` را نمایش می‌دهد. برای همهٔ مثال‌ها:

```bash
python examples/03-basics.py
```

اسکریپت دوم خروجی مثال‌ها را پشت‌سرهم نمایش می‌دهد؛ برای توضیح هر قسمت، شناسهٔ C در متن کامل را ببینید. این اسکریپت آزمون خودکار نیست؛ خطای منطقی C22 نیز عمداً نمایش داده می‌شود و سپس شکل صحیح می‌آید.

## اجرای دفترچه

JupyterLab را از محیط فصل دوم اجرا و فایل دفترچه را باز کنید. هستهٔ همان محیط را انتخاب کنید. برای هر مثال ابتدا خروجی را پیش‌بینی کنید و سپس اجرا کنید. در پایان، هسته را تازه و همهٔ سلول‌ها را از بالا اجرا کنید؛ عنوان دقیق فرمان ممکن است با نسخهٔ رابط فرق کند.

دفترچه فقط از کتابخانهٔ استاندارد Python استفاده می‌کند؛ بستهٔ تحلیلی جدیدی لازم نیست. برای خودِ رابط دفترچه، JupyterLab و ipykernel فصل دوم همچنان لازم‌اند. فایل نیازمندی تازه یا قفل نسخهٔ ساختگی اضافه نشده است.

**نکتهٔ تغییر ورودی:** C23 و C24 مثال‌های مستقل‌اند. اگر ورودی C23 را تغییر دهید، C24 ورودی‌های خودش را دارد و خودکار به سناریوی جدید تبدیل نمی‌شود؛ برای کنترل سناریوی تازه، آن‌ها را هماهنگ کنید.

## آزمون‌های بازبینی

از پوشهٔ فصل اجرا کنید:

```bash
python -m unittest discover -s tests -v
```

ابزار آزمون، پیش‌نیاز درک این فصل نیست. نحو پیشرفته‌ترِ فایل آزمون برای بازبین نوشته شده و در فصل‌های بعد آموزش داده می‌شود. برای اجرای همین آزمون‌ها، نصب pytest لازم نیست.

آزمون‌ها خروجی همهٔ ۲۸ بلوک سالم، نوع شش خطای عمدی، نمونه‌های مرزی و تطابق کد دفترچه با متن را بررسی می‌کنند. بررسی ترتیبی سلول‌ها در یک فضای نام Python، با اجرای واقعی پروتکل Jupyter kernel متفاوت است. **در بازبینی این بسته، هر دو روش اجرا شده‌اند** و خروجی ۲۴ سلولِ دفترچه در هستهٔ واقعی نیز با متن تطبیق داده شده است؛ جزئیات و محدودیت‌ها در گزارش آزمون آمده‌اند.

برای تکرار اختیاری بررسی هسته، در محیطی که `nbformat`، `nbclient` و هستهٔ `python3` دارد:

```bash
python tests/check_notebook_kernel.py
```

این بررسی به ابزارهای توسعهٔ بیشتری نسبت به آزمون استاندارد نیاز دارد، اما برای مطالعه یا اجرای کد آموزشی فصل لازم نیست. دفترچهٔ منتشرشده را تغییر نمی‌دهد و رابط مرورگر را نمی‌آزماید.

## فرض‌ها و هشدارها

- قیمت و تعداد در سناریوی اصلی صحیح و مبلغ‌ها تومان هستند.
- بازپرداخت کامل با همان قیمت اولیه انجام می‌شود؛ تخفیف، مالیات و ارسال نداریم.
- مبلغ اولیه مثبت و تعداد مرجوعی در محدودهٔ مجاز فرض شده است.
- کد کوتاه کارگاه، اعتبارسنج ورودی دلخواه نیست؛ صفر بودن مخرج عمداً خطا ایجاد می‌کند، نه نرخ ساختگی.
- در گزارش نسخه‌ها، محیط واقعاً آزموده‌شده را بنویسید؛ سازگاری نسخه‌ایِ آزموده‌نشده را فرض نکنید.
- سه تصویر نهایی تولید نشده‌اند؛ پرامپت‌ها در محل درج متن آمده‌اند.
