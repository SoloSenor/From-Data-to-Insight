# ردیابی منابع فصل سوم

این جدول، پشتوانهٔ علمی مباحث و سهم تألیفی فصل را مشخص می‌کند. **بررسی بخش‌های مرتبط، به معنی مطالعهٔ خط‌به‌خط تمام منابع نیست.** نسخه‌های PDF و متن استخراج‌شدهٔ آن‌ها در موجودی پروژه قرار دارند؛ خود منابع در بستهٔ فصل بازتوزیع نمی‌شوند.

**نکتهٔ شمارهٔ صفحه:** شماره‌ها نشانگر صفحه در فایل استخراج‌شده‌اند و ممکن است با شمارهٔ چاپی کتاب فرق داشته باشند؛ عنوان بخش، شناسهٔ اصلی ارجاع است. داده‌های شناسنامه‌ای نامطمئن برای نسخهٔ موجود S2 حدس زده نشده‌اند.

## ۳. بازبینی‌های علمی و نسخه‌ای

- توضیح ساده‌شدهٔ «حذف اعشار» برای `//` به کار نرفته است؛ رفتار منفی با `-7 // 2` بررسی می‌شود.
- قابل‌نمایش نبودن دقیق **بسیاری** از کسرهای ده‌دهی توضیح داده شده؛ ادعا نشده همهٔ اعشارها تقریبی‌اند یا فقط عددهای توانِ دو دقیق‌اند.
- `Decimal` معادل دقت نامحدود معرفی نشده است.
- نامعتبر بودن `int("3.0")` از تبدیل عدد `int(3.0)` جدا شده است.
- `and` و `or` به‌طور عمومی، همیشه تولیدکنندهٔ bool معرفی نشده‌اند.
- None معادلِ تمام گونه‌های دادهٔ گمشده در کتابخانه‌های آینده معرفی نشده است.
- هیچ API قدیمیِ کتابخانه‌های تحلیل داده در این فصل استفاده نمی‌شود. کد آموزشی فقط به کتابخانهٔ استاندارد متکی است.
- بازهٔ نسخه‌های آزموده‌شده، صرفاً همان است که گزارش آزمون ثبت می‌کند؛ سازگاری با شاخهٔ هدف 3.14 بدون اجرای واقعی، تأییدشده اعلام نمی‌شود.

## ۴. مستندات رسمی برای مطالعهٔ تکمیلی

نشانی‌های رسمی در انتهای متن کامل معرفی شده‌اند. آن‌ها راهنمای مطالعه‌اند؛ در این نوبت گزارش واکشی تازهٔ همهٔ این صفحات ارائه نمی‌شود. شاهد اجرای نمونه‌ها، خروجی آزمون‌های همین بسته است؛ آزمون نمونه، معادل تضمین رفتار همهٔ ورودی‌ها نیست.

## ۵. حقوق منابع

فصل، ترجمهٔ پیوسته یا گردآوری بندهای منابع نیست. نمودارهای پیشنهادی برای همین کتاب طراحی شده‌اند و تصویر منبع بازنشر نمی‌شود. نام متدها، دستورهای استاندارد و مثال‌های حداقلیِ رفتار زبان، برای آموزش و آزمون استفاده شده‌اند. هیچ ادعای نقل مستقیم یا مطالعهٔ کامل منابع مطرح نیست.
