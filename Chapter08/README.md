# فصل هشتم: توابع، ماژول‌ها و سازمان‌دهی برنامه

این بسته مستقل از پوشهٔ منابع و فصل‌های دیگر اجرا می‌شود. تمام کدها، رشته‌ها، توضیحات داخل کد و خروجی‌های آموزشی انگلیسی و ASCII هستند؛ توضیح فارسی بیرون کد است.

## مسیر مطالعه
۱. [متن کامل Markdown](chapter-08-full-fa.md) یا [متن کامل متنی](chapter-08-full-fa.txt)
۲. [خلاصهٔ تخصصی](chapter-08-summary-fa.md)
۳. [دفترچهٔ آموزشی](notebooks/08-functions-and-modules.ipynb)
۴. [نقشهٔ منابع](SOURCE-MAP.md) و [گزارش کیفیت](TEST-REPORT.txt)

فصل شامل ۳۰ مثال، ۱۲ تمرین (۴ مفهومی و ۸ کدنویسی با پاسخ)، ۶ خطای عمدی جداگانه و کارگاه چندفایلی است. جایگاه تصویر و پرامپت در متن آمده؛ تصویر نهایی ساخته نشده است.

## محیط
محیط مرجع اجرا Python 3.11.16 روی Linux است. اجرای تحلیل و مثال‌ها کتابخانهٔ بیرونی لازم ندارد. نسخه‌های دیگر و سیستم‌های عامل دیگر آزموده نشده‌اند. کد راهنمای نوع از نحو جدید Python استفاده می‌کند؛ این بسته برای Python 2 نیست.

فرمان‌های زیر را از پوشهٔ استخراج‌شدهٔ فصل اجرا کنید. در بعضی محیط‌ها باید به جای python از python3 استفاده کنید.

```bash
python run_analysis.py
python -m order_report
python examples/08-examples.py
python examples/08-answers.py
```

دو فرمان نخست باید گزارش یکسان بدهند:

```text
orders 12
gross_toman 5020000
refund_toman 1430000
retained_toman 3590000
Digital 2450000 68.25%
Books 690000 19.22%
Stationery 450000 12.53%
```

نمونه‌ها درون هر فایل ترتیبی‌اند؛ بعضی به تعریف‌های پیشین وابسته‌اند. فایل پاسخ‌ها دادهٔ لازم را خودش آماده می‌کند. اسکریپت اصلی و مثال‌ها با مسیر مطلق از پوشهٔ کاری دیگر نیز آزموده شده‌اند. فرمان ماژولی باید از پوشهٔ فصل یا با مسیر جست‌وجوی مناسب اجرا شود؛ بسته با pip نصب نشده است. فایل‌های داخلی دارای import نسبی را مستقیم اجرا نکنید.

## دفترچه و ابزار کنترل کیفیت
برای تحلیل اصلی نصب ابزار دفترچه لازم نیست. برای دفترچه و مجموعهٔ کامل آزمون‌ها:

```bash
python -m pip install -r requirements-qa.txt
python -m unittest discover -s tests -v
python tests/check_notebook_kernel.py
```

نسخه‌های ثبت‌شده نسخه‌های مستقیم مشاهده‌شده‌اند، نه قفل همهٔ وابستگی‌های گذرا یا تضمین نصب تازه. آزمون هسته به kernelspec با نام python3 نیاز دارد. اگر هسته ثبت نشده باشد، در محیط درست:

```bash
python -m ipykernel install --user --name python3
```

دفترچهٔ تحویلی عمداً بدون خروجی و execution count است؛ اجرای کنترل کیفیت در حافظه انجام شده و نسخهٔ تحویلی را تغییر نمی‌دهد. دفترچه هیچ داده یا ماژول محلی وارد نمی‌کند و با پوشهٔ کاری موقت نیز اجرا شده است. هستهٔ واقعی آزموده شده، نه رابط مرورگری JupyterLab.

## داده و دامنهٔ تضمین
[data/orders.json](data/orders.json) شامل همان ۱۲ سفارش ساختگی فصل‌های قبل است؛ نسخهٔ آماده در sample_data.py اجازه می‌دهد کارگاه پیش از آموزش فایل‌خوانی اجرا شود. آزمون، برابری این دو نسخه را کنترل می‌کند.

build_report یک اعتبارسنج عمومی نیست: رکوردها باید از قبل معتبر باشند؛ فقط شناسهٔ تکراری صریحاً رد می‌شود. ورودی یک فهرست قابل‌پیمایش مجدد است. کپی رکوردها کم‌عمق است. حداقل مبلغ در format_report فقط فیلتر نمایش است و مخرج سهم‌ها را تغییر نمی‌دهد. مبلغ باقی‌مانده سود نیست.

[outputs/report.json](outputs/report.json)، [گزارش متنی](outputs/report.txt) و [گزارش فیلترشده](outputs/report-filtered.txt) خروجی‌های مرجعِ ازپیش‌ساخته‌اند. برنامهٔ تحلیل آنها را نمی‌نویسد؛ فقط روی کنسول چاپ می‌کند. واردکردن ماژول‌ها گزارش چاپ نمی‌کند و فایل داده یا گزارش نمی‌سازد؛ Python ممکن است حافظهٔ نهان معمول import را بسازد.

خطاهای عمدی در examples/intentional-errors.json هستند؛ در مسیر سالم دفترچه و اسکریپت آموزشی قرار ندارند. آنها را جدا و با انتظار شکست اجرا کنید.

## انتقال به Word
کد و خروجی را در پاراگراف مستقل چپ‌به‌راست با قلم تک‌عرض قرار دهید. تورفتگی چهار فاصله‌ای، علامت‌های ASCII و نقل‌قول مستقیم حفظ شوند. این بسته DOCX نیست و صفحه‌آرایی واقعی Word آزموده نشده است.
