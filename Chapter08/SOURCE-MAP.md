# نقشهٔ منابع فصل هشتم

## شیوهٔ استفاده
این فصل تألیفی است. منابع، پشتوانهٔ مفهومی‌اند؛ متن از ترجمه یا کنارهم‌چیدن آنها ساخته نشده است. شماره‌های زیر، خط در متن استخراج‌شده‌اند، نه شمارهٔ صفحهٔ چاپی. بازبینی کامل همهٔ صفحات ادعا نمی‌شود.

| اولویت | منبع | بخش بازبینی‌شده در متن استخراج‌شده | کاربرد |
|---|---|---|---|
| اصلی | Introducing Python O’Reilly Media - 2019 | خطوط 5800–6009؛ آرگومان موقعیتی و کلیدی، پیش‌فرض و ستاره | فراخوانی، زمان ارزیابی پیش‌فرض و دام فهرست مشترک |
| اصلی | همان منبع | خطوط 6100–6189؛ تغییر آرگومان، docstring و تابع به‌عنوان شیء | اثر جانبی، قرارداد و ارسال تابع |
| اصلی | همان منبع | خطوط 8156–8350؛ فصل Modules, Packages, and Goodies | import، نام مستعار، تقسیم چندفایلی و بسته |
| مکمل | Python for Data Analysis | خطوط 3565–3714؛ بخش Functions | مقدار بازگشتی، دامنه، تاپل و تابع به‌عنوان ورودی |
| پیوستگی | فصل هفتم همین کتاب | متن فصل و data/orders.json | ادامهٔ قرارداد رکورد، کپی کم‌عمق و گروه‌بندی |
| کنترل عددی | فصل ششم همین کتاب | data/orders.csv و جمع مرجع | ثابت‌ماندن داده و اعداد هنگام بازآرایی |

متن‌های استخراج‌شده در /mnt/data/review هستند و برای جلوگیری از بازتوزیع غیرضروری منابع در ZIP فصل قرار نگرفته‌اند. اجرای مثال‌ها به منابع نیاز ندارد.

## اصلاح و احتیاط
- عبارت ساده‌سازِ منبع دربارهٔ کپی‌شدن «مقادیر آرگومان» به معنی کپی مستقل شیء منتقل نشده است. تفاوت انتساب نام و تغییر ظرف با مثال اجرایی توضیح داده می‌شود.
- پارامتر پیش‌فرض‌دار با پارامتر فقط کلیدی یکی نیست. امضا و محدودیت فراخوانی جداگانه بررسی می‌شوند.
- مدل محلی و سراسری به‌تنهایی برای همهٔ مثال‌ها کافی نیست؛ دامنهٔ دربرگیرنده نیز نشان داده می‌شود. این مدل شرح جامع همهٔ دامنه‌های Python نیست.
- package را به «هر پوشه» یا «بستهٔ قابل‌نصب» تقلیل نمی‌دهیم. در کارگاه بستهٔ معمولی با __init__.py ساخته می‌شود؛ namespace package و انتشار بسته آموزش داده نمی‌شود.
- ساختار چندفایلی، محافظ نقطهٔ ورود، نحو راهنمای نوع و رفتار امضای فقط کلیدی با اجرای مستقل روی Python مرجع بررسی شده‌اند؛ ادعای پشتیبانی نسخه‌های دیگر یا انتساب همهٔ این جزئیات به منابع قدیمی نداریم.
- راهنمای نوع با اعتبارسنجی اجرا یکسان نیست؛ خطای قراردادیِ قیمت منفی ممکن است بدون استثنا نتیجهٔ عددی بدهد.

## سهم تألیفی و کنترل مستقل
۳۰ مثال، ۱۲ تمرین، خطاهای عمدی و معماری order_report برای این فصل طراحی شده‌اند. معیار عددی مستقل با جمع قیمت واحدهای کالا در نمونه‌های کوچک ساخته شده است. جداسازی محاسبه، ساخت گزارش، قالب‌بندی و چاپ، تمرین بازآرایی است. فیلتر نمایش عمداً مخرج سهم‌ها را تغییر نمی‌دهد. منابع جای آزمون اجرای کد یا بررسی معنای شاخص را نمی‌گیرند.
