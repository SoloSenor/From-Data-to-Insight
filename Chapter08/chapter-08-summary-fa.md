# خلاصهٔ تخصصی فصل هشتم
## توابع، ماژول‌ها و سازمان‌دهی برنامه

### ایدهٔ محوری
تابع مرز قرارداد و ماژول مرز مسئولیت و فضای نام است. بازآرایی باید استفادهٔ مجدد و آزمون‌پذیری را بهتر کند، بدون تغییر معنای شاخص یا نتیجهٔ محاسبه.

## ۱. قرارداد تابع
پنج پرسش: چه می‌گیرد؟ چه برمی‌گرداند؟ چه چیزی را تغییر می‌دهد؟ واحدها چیست؟ کدام ورودی خارج از قرارداد است؟

| مفهوم | نکتهٔ کلیدی |
|---|---|
| پارامتر و آرگومان | نام در تعریف با مقدار ارسال‌شده یکی نیست |
| return و print | اولی نتیجه می‌دهد؛ دومی اثر جانبی نمایش دارد |
| نبود return | پایان عادی تابع مقدار None برمی‌گرداند |
| نتیجهٔ چندگانه | یک تاپل بازگردانده و سپس باز می‌شود |
| راهنمای نوع | ابزار مستندسازی و تحلیل ایستا؛ نه اعتبارسنجی خودکار اجرا |
| docstring | نخستین عبارت رشته‌ای در بدنه؛ محل بیان قرارداد و محدودیت |

## ۲. امضا و فراخوانی
```python
def order_amounts(quantity: int, unit_price_toman: int,
                  returned_quantity: int = 0) -> tuple[int, int, int]:
    gross = quantity * unit_price_toman
    refund = returned_quantity * unit_price_toman
    return gross, refund, gross - refund
```

- پارامتر معمولی می‌تواند هم موقعیتی و هم کلیدی باشد؛ داشتن پیش‌فرض آن را فقط کلیدی نمی‌کند.
- پارامتر پس از ستارهٔ تنها در تعریف، فقط با نام ارسال می‌شود.
- ستاره در تعریف، آرگومان‌های موقعیتی اضافی را در تاپل جمع می‌کند؛ دو ستاره، کلیدی‌ها را در دیکشنری.
- همین علامت‌ها در فراخوانی، ظرف را باز می‌کنند. args و kwargs نام قراردادی‌اند، نه واژهٔ رزروشده.
- مقدار پیش‌فرض هنگام اجرای تعریف ارزیابی می‌شود؛ نه در هر فراخوانی.

## ۳. دامنه، تغییر و مالکیت
- نام‌یابی معمول در مثال‌های فصل: محلی، دربرگیرنده، سراسری ماژول و builtins؛ این مدل ساده‌شده، شرح همهٔ قواعد دامنهٔ Python نیست.
- انتساب دوباره به پارامتر، نام محلی را به شیء دیگری وصل می‌کند؛ شیء فراخواننده را خودکار جایگزین نمی‌کند.
- تغییر ظرفِ مشترک می‌تواند بیرون تابع دیده شود. ارسال آرگومان، کپی خودکار شیء نیست.
- پیش‌فرض فهرستی ممکن است میان فراخوانی‌ها مشترک بماند. None همراه ساخت فهرست تازه این دام را رفع می‌کند.
- اگر حفظ ورودی هم شرط است، فهرستِ صریحِ دریافتی را نیز کپی کنید. صرف استفاده از None این تضمین را نمی‌دهد.
- کپی دیکشنریِ رکوردها در کارگاه کم‌عمق است؛ داده‌های تودرتوی افزوده‌شده ممکن است مشترک بمانند.

## ۴. تابع و شیء
تابع یک شیء قابل‌فراخوانی است؛ می‌تواند ورودی تابع دیگر باشد. نام تابع بدون پرانتز با نتیجهٔ فراخوانی آن متفاوت است. دسترسی با نقطه لزوماً متد نیست؛ ویژگی ممکن است عدد باشد. متدها الزاماً تغییر‌دهنده نیستند و متد تغییر‌دهنده ممکن است None برگرداند.

## ۵. معماری کارگاه
| فایل | مسئولیت |
|---|---|
| order_report/metrics.py | محاسبهٔ مبلغ، غنی‌سازی و جمع گروهی |
| order_report/reporting.py | کنترل تکرار شناسه، ساخت گزارش، رتبه و قالب‌بندی |
| order_report/sample_data.py | ساخت فهرست تازه‌ای از داده‌های نمونه |
| order_report/cli.py | مرز چاپ و تابع main |
| run_analysis.py | اجرای اسکریپتی با محافظ نقطهٔ ورود |
| order_report/__main__.py | اجرای بسته با فرمان ماژولی |

- import ممکن است کد سطح بالای ماژول را اجرا کند؛ محافظ نقطهٔ ورود مانع اجرای ناخواستهٔ main هنگام import می‌شود، نه مانع همهٔ اثرهای جانبی ممکن.
- import معمولاً از ماژول بارگذاری‌شدهٔ همان فرایند استفاده می‌کند؛ آن را با اجرای مجدد برنامه اشتباه نگیرید.
- ماژول محلی را هم‌نام کتابخانهٔ استاندارد نام‌گذاری نکنید.
- پوشهٔ package در این کارگاه، بستهٔ قابل‌نصب با pip نیست.

## ۶. قرارداد داده و شاخص
داده، ۱۲ سفارش ساختگی و مشترک با فصل‌های ششم و هفتم است. ورودیِ build_report فهرست رکوردهای معتبر و قابل پیمایش مجدد است؛ iterator یک‌بارمصرف خارج از قرارداد است. فقط شناسهٔ تکراری صریحاً رد می‌شود؛ تابع اعتبارسنج عمومی schema نیست.

| شاخص مرجع | تومان |
|---|---:|
| مبلغ اولیه | ۵٬۰۲۰٬۰۰۰ |
| بازپرداخت | ۱٬۴۳۰٬۰۰۰ |
| مبلغ پس از مرجوعی | ۳٬۵۹۰٬۰۰۰ |

مبلغ پس از مرجوعی، سود یا لزوماً جریان نقدی دوره نیست. سهم‌ها از کل مبلغ باقی‌مانده محاسبه می‌شوند. مخرج صفر، سهم تعریف‌نشده و نمایش NA دارد. حداقل مبلغ در قالب‌بندی فقط فیلتر نمایش است؛ نه مخرج سهم‌ها را عوض می‌کند و نه گزارش ورودی را.

## ۷. چک‌لیست عبور
- تفاوت چاپ، نتیجه و اثر جانبی را می‌توانم توضیح بدهم.
- رفتار پیش‌فرض تغییرپذیر و تغییر ظرف مشترک را پیش‌بینی می‌کنم.
- وابستگی سراسری را به ورودی صریح تبدیل می‌کنم.
- قرارداد و واحدها را مستند و راهنمای نوع را از کنترل واقعی جدا می‌کنم.
- دو نقطهٔ ورود را اجرا و نبود چاپ گزارش هنگام import را بررسی می‌کنم.
- حفظ اعداد مرجع را با حفظ معنای شاخص اشتباه نمی‌گیرم.
